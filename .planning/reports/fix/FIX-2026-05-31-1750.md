## Root Cause
The `products` table stores branded (non-Aquad'or) fragrances as one row per size, sharing a base slug (e.g. `imagination-by-louis-vuitton` 50ml + `imagination-by-louis-vuitton-100ml`). All four listing routes (`/shop`, `/shop/[category]`, `/shop/gender/[gender]`, `/shop/lattafa`) passed those raw rows into their grids with no variant collapse, so each size rendered as its own card. Aquad'or house products are a single DB row (sizes synthesized client-side by `ProductVariantSelector`) and were never the source of duplication.

## Patch (v4.0)
- `src/lib/supabase/variants.ts` (new) — pure module (no React/Supabase imports): `getVariantBaseId`, `collapseToFragranceCards`. Groups rows by base slug, keeps the canonical representative (base row, else smallest size), preserves first-seen order. Pure so it is unit-testable without a server runtime (product-service's top-level `cache()` call throws under Jest).
- `src/lib/supabase/product-service.ts` — re-exports `collapseToFragranceCards` from `./variants` so pages import it alongside the data fetchers.
- `src/app/shop/page.tsx`, `src/app/shop/[category]/page.tsx`, `src/app/shop/gender/[gender]/page.tsx`, `src/app/shop/lattafa/page.tsx` — wrap their product lists in `collapseToFragranceCards`.
- `src/lib/supabase/__tests__/collapse-variants.test.ts` (new) — 6 cases pinning the contract.
- `.gitignore` — add `.env.production` (was untracked + unignored).

## Remaining Notes — FOLLOW-UP NEEDED
- **Branded multi-size reachability.** v4.0 PDPs for branded products (`isAquador === false` in `ProductDetails.tsx`) have NO size selector — each size is a standalone page. Collapsing the grid to the base (50ml) row means a branded fragrance's 100ml is no longer reachable by browsing (only by direct URL/search). To fully honor "choose size on the product page" for branded items, the branded PDP needs a size selector that fetches the sibling size rows (`-100ml`, etc.). This is a feature (PDP + product-service + cart wiring), not a hotfix — recommend `/qualia-plan`. Aquad'or house products already have the selector and are unaffected.
